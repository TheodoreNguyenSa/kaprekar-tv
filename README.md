# Kaprekar 6174 — Android TV

Discover **Kaprekar's constant 6174** on your TV. Type any 4-digit number (not four identical digits), and the app repeatedly sorts the digits descending minus ascending — every number is pulled into the same attractor: **6174**, in at most 7 steps.

Example: 2026 takes exactly 6 steps. 1000 takes 5 steps. And 6174 maps to itself: 7641 − 1467 = 6174.

Discovered by Indian mathematician D. R. Kaprekar in 1949 — one of the most famous "number black holes" in recreational mathematics.

## Features

- On-screen number pad designed for the TV remote (D-pad + OK)
- Step-by-step chain shown in big, easy-to-read type, with a final "Reached 6174 in N steps!" banner
- Leading zeros are kept, so numbers like 1000 → 0999 work exactly as the routine requires
- Four identical digits (1111, 2222, ...) are rejected with a clear message
- 4 languages: English, Français, Tiếng Việt, 中文 — your choice is remembered
- Background music with MUTE support, fully offline
- "Buy me a coffee" QR panel
- Automatic update check against this repository's latest release
